# 访谈稿匿名化映射编辑器

在浏览器中对访谈稿进行匿名化：维护人物代号与称呼映射，自动识别称呼命中，支持鼠标框选显式指派，可把个别称呼命中标为「保留原文」例外，并可将一位人物合并进另一位（称呼去重、框选与例外一并迁移，整次合并可原子撤销）。所有结果仅体现在匿名预览中，原稿永不改动，并维护原稿 ↔ 预览的双向字符区间映射。

## 一键启动（Docker Compose）

```bash
docker compose up --build
```

启动后在浏览器访问：**http://localhost:3000**

> 端口固定为 `3000`（`docker-compose.yml` 中映射 `"3000:3000"`）。停止服务：`Ctrl+C`；后台运行：`docker compose up --build -d`。

不使用 Docker 时也可直接运行（需 Node.js 18+）：

```bash
npm install
npm start
# 访问 http://localhost:3000
```

## 操作说明

1. **粘贴原稿**：首页文本框粘贴访谈稿，点击「加载原稿，开始匿名化」；或点击顶部「加载内置示例」快速体验。
2. **维护人物规则**：在右侧填写「统一代号 + 称呼（多个用逗号分隔）」并添加人物。自动识别遵循**最长称呼优先**（长度相同则先出现者优先）。
3. **显式框选（最高优先级）**：在原稿中用鼠标框选任意片段，在弹窗中指派给已有或新建人物。框选可覆盖、切开任何称呼命中与保留原文例外。
4. **保留原文例外**：
   - 在底部「字符区间映射表」中，对任一**称呼命中**行点击「保留原文」，该处即成为例外：预览中原样照录，并屏蔽与该区间重叠的所有自动称呼命中；
   - 右侧「保留原文例外」列表展示每个例外的**原稿片段**与**来源人物**（点击片段可在原稿/预览中定位）；
   - 点击例外列表或映射表中的「恢复匿名」即可删除例外、恢复自动匿名；
   - 若某例外被显式框选**完全覆盖**，列表中会置灰标注（被部分覆盖时，未覆盖部分仍然保留原文）。
5. **合并人物**：在人物列表中点击目标人物上的「合并」，在弹窗中选择要并入的**源人物**。弹窗会列出双方代号、去重后的称呼，以及将迁移的框选与保留原文例外数量；确认后源人物的称呼（去重）、框选与例外统一改绑到目标人物，源人物删除，重叠称呼仍按**最长称呼优先**处理。
6. **双向高亮**：点击或悬停原稿/预览中的高亮片段，可在两侧及映射表间联动定位；点击映射表行同样定位。
7. **撤销**：顶部「撤销最近操作」按时间倒序撤销，涵盖添加人物、显式框选、**标记例外、恢复匿名、删除人物、合并人物**（删除人物会连同其框选与例外一并恢复；合并作为一次原子操作撤销，源人物按原 ID、原列表位置、原称呼及全部关联区间精确恢复）。
8. **复制结果**：点击「复制匿名预览」复制匿名后的完整文本。
9. **重新粘贴**：点击「重新粘贴原稿」可清空全部规则、框选与例外后重新开始。

底部统计与映射表会随以上任何操作实时重算（人物数、框选 / 称呼 / 保留原文处数、被框选完全覆盖的例外数）。

## 目录结构

```
server.js            Express 静态服务 + /api/example 内置示例
example.json         内置示例数据（原稿 + 预置人物规则）
public/anonymize.js  匿名化引擎（纯函数，浏览器/Node 共用）
public/app.js        前端交互（规则、框选、例外、撤销栈、渲染）
public/index.html    页面结构
public/style.css     样式
```
